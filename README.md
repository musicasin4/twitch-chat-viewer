# Twitch VOD Chat Viewer V2

- Não exige mais URL/ID de VOD.
- O tempo das mensagens é somente informativo e não é clicável.
- Pesquisa por usuário ou palavra.
- Clique no nome para filtrar o usuário.
- Badges e emotes são renderizados como imagens.
- Para emotes Twitch personalizados do canal, informe o canal da Twitch (opcional).
- Para buscar emotes nativos da Twitch via Helix, configure `TWITCH_CLIENT_ID` e `TWITCH_CLIENT_SECRET` no Render. A Twitch documenta que os endpoints de emotes retornam o nome e as URLs das imagens.
- CSV/XLSX continuam sendo aceitos.
